# sql-data-warehouse-project
Construindo um noderno Data Warehouse com SQL Server, incluindo ETL process, modeling data e analytics 

# Projeto de Armazém de Dados e Análise de Dados

Este projeto tem como objetivo desenvolver uma solução que permita organizar, integrar e analisar dados de vendas de uma empresa. O trabalho está dividido em duas partes principais: a construção de um armazém de dados e a realização de análises para apoiar a tomada de decisões.

# 1. Construção do Armazém de Dados (Engenharia de Dados)

# Objetivo

Criar um armazém de dados utilizando o SQL Server, reunindo informações de vendas provenientes de diferentes sistemas, de modo a facilitar o acesso aos dados e a elaboração de relatórios.

Requisitos

- Fontes de dados: Importar ficheiros CSV provenientes de dois sistemas: ERP e CRM.
- Limpeza dos dados: Identificar e corrigir erros, eliminar duplicações e resolver outros problemas que possam comprometer a qualidade dos dados.
- Integração dos dados: Reunir as informações dos dois sistemas num único modelo de dados, organizado e adequado para consultas e análises.
- Âmbito do projeto: Trabalhar apenas com os dados mais recentes, sem necessidade de guardar o histórico das alterações.
- Documentação: Documentar a estrutura do modelo de dados, explicando a sua organização e facilitando a utilização por parte das equipas de negócio e de análise de dados.

## 2. Análise de Dados e Relatórios de BI

# Objetivo

Utilizar o SQL para analisar os dados de vendas e obter informações relevantes sobre o desempenho do negócio.

A análise será centrada em três áreas principais:

- Comportamento dos clientes: Compreender os hábitos de compra, identificar os clientes mais ativos e analisar os seus padrões de consumo.
- Desempenho dos produtos: Identificar os produtos mais vendidos e avaliar o seu contributo para os resultados da empresa.
- Tendências de vendas: Analisar a evolução das vendas e identificar padrões que possam ajudar a compreender o desempenho comercial.

# Resultado esperado

No final do projeto, pretende-se ter uma base de dados organizada e integrada, acompanhada de análises que permitam compreender melhor o comportamento dos clientes, o desempenho dos produtos e a evolução das vendas. Estas informações servirão de apoio à tomada de decisões e ao planeamento das estratégias da empresa.
